# 📊 Marketing A/B Testing：提升廣告轉換率之統計分析
## 🎯 專案摘要（Executive Summary）
本專案透過分析 58 萬筆用戶數據，針對「商業廣告 (AD)」與「公益廣告 (PSA)」進行 A/B Testing。利用 Python 進行統計檢定（Z-檢定、卡方檢定），驗證廣告投放對轉換率的影響。

結果顯示廣告組轉換率顯著高於對照組（提升約 43%），並據此提出商業決策建議。


## 🛠 核心技術（Tech Stack）
- 語言：Python 3.10+
- 數據處理：Pandas, NumPy
- 統計分析：Scipy, Statsmodels (Z-test, Chi-square Test)
- 視覺化：Matplotlib, Seaborn


## 📝 專案描述
【Situation：情境】

公司希望評估行銷廣告的實際成效。為了排除用戶「自然購買」的偏差，設計了實驗組（看到『商業廣告』）與對照組（看到『公益廣告』），需透過數據分析確認廣告是否能顯著提升轉換率 (Conversion Rate)。

【Task：任務】

1. 清理並驗證 588,101 筆原始數據的完整性。
2. 處理實驗中的「用戶污染 (User Pollution)」問題。
3. 計算兩組轉換率，並進行統計學上的顯著性檢定（Hypothesis Testing）。
4. 產出視覺化圖表供決策層參考。

【Action：行動】

- 數據清洗：使用 Pandas 檢查重複值與缺失值，並過濾同時出現在兩組的異常用戶（User Pollution Check）。
- 統計模型：
    1. 執行 Z-test for Proportions 計算 P-value 與 95% 信賴區間。
    2. 執行 Chi-square Test of Independence 驗證廣告與轉換行為的關聯性，確保結論的穩健性。

  🌟 針對樣本不平衡（96% vs 4%）進行統計效力評估，確認大數法則下結果依然可靠。

【Result：結果】

- 關鍵指標：廣告組轉換率為 2.55%，對照組為 1.79%。
- 統計結果：P-value<0.001，Z 分數為 7.37，代表結果具有極高度統計顯著性。
- 商業價值：廣告帶來了 43% 的相對提升。建議公司全面投放商業廣告，預計每萬次曝光可額外創造約 76 筆訂單。


## 👁️ 專案洞察（Insights & Challenges）
Question：樣本不對等會帶來哪些統計挑戰？
1. 統計檢定力（Statistical Power）的流失：

  - 當兩組樣本數量差異極大時，最直接的挑戰就是檢定力不足。
  - 信賴區間擴大：小樣本組的標準誤差（Standard Error）會非常大。這意味著即便兩組之間真的存在顯著差異，統計檢定也可能因為「證據不足」而無法檢測到（Type II Error, False Negative）。
  - 「稀有事件」的偏差：在小樣本組中，只要出現一個極端值（Outlier），就會大幅拉低或拉高平均數，導致結果被個別案例『綁架』。

2. 變異數同質性（Homogeneity of Variance）的破壞：
  
  - 許多經典統計方法（如 t-檢定 或 ANOVA）都假設各組的變異數（資料的分散程度）是相等的。
  - 當樣本對等時：即使變異數稍有不等，檢定結果通常還算穩健。
  - 當樣本不對等時：若小樣本組的變異數很大，會導致 $𝑝$ 值被低估，增加誤判為「顯著差異」的風險（Type I Erroe, False Positive）。
3. 預測模型的「大多數偏誤」（Majority Bias）：
  
  - 在機器學習（分類問題）中，樣本不對等會讓模型變得『懶惰』。
  - 準確率陷阱：假設資料中有 99% 是健康的人，1% 是病人。模型只要「預測所有人都是健康的」，準確率就能達到 99%，但它就會完全失去了找出病人的能力。
  - 邊界偏移：模型的決策邊界會被大樣本組推向小樣本組，導致對少數類別的預測極其不準確。

‼️ 樣本不對等不代表研究失效，而是表示需改用更嚴謹、更能反映資料真實分佈的分析工具

**【商業洞察與行動建議】**
- **流量與品質的錯位**：透過雙軸趨勢圖可以發現，系統最高流量的時段（長條圖高峰）未必是轉換率（折線圖高峰）最好的時段。
-  **預算優化策略**：建議行銷團隊不應盲目將預算砸在「流量最高」的時段。對於那些 **「流量基數中等，但轉換率表現異常突出」** 的黃金時段，應加大廣告競價（Bidding）與曝光權重，以更低的獲客成本（CAC）最大化整體 ROI。
